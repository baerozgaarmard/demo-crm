# Contributing

Thanks for taking a look at this project. It is maintained by
Ayush Bhatt at BrandForge Media — issues and pull requests are welcome.

## Reporting a problem

Open an issue with:

- What you expected to happen
- What actually happened
- Steps to reproduce it (commands, inputs, screenshots if relevant)
- Your environment (OS, Python/Node version) if it matters

## Making a change

1. Fork the repository and create a branch from `main`
   (`git checkout -b fix/short-description`).
2. Make your change, keeping it focused on one problem or feature.
3. Test locally before opening a pull request — say in the PR description
   how you tested it.
4. Open a pull request against `main` with a clear title and a short
   summary of what changed and why.

## Style

- Match the style of the surrounding code; don't reformat unrelated files.
- Keep commits small and write commit messages that explain the *why*,
  not just the *what*.

Small fixes (typos, docs) can go straight to a pull request without an
issue first.
